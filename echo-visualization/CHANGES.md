# echo-visualization 改动说明

## 为什么画不出那张图（诊断）

原技能本身没坏：8 个模板用无头 Chrome 实测都能渲染，G2 5.4.8 的 CDN 可以访问，断网时也会正确降级成表格。
画不出来，是因为技能里根本没有这类图的路子，有几处规则还会把模型往别的方向带：

1. **规则不让画双轴**。原文写的是「不同单位不要共用一根 y 轴……拆成上下两张小图」，可目标图恰好就是双轴（概率% + 收益率%）。
2. **只有一个单线模板**。01 只演示了「同一单位、类目 x 轴的折线」。柱+线组合、右轴、固定范围、两轴零点对齐，一样都没讲。
3. **参考线、条件色、点标注都没有给做法**。原文还写了「竖线去掉」，模型很容易连有含义的点位虚线一起省掉。
4. **G2 v5 有几个不试不知道的坑**（这次实测踩到的）：
   - 柱子用 `interval` 时 x 是类目，3674、3934 这种不在类目里的值，参考线落不上去。
   - text 的 `rotate` / `transform` 写了不生效，得用 `labelTransform`。
   - classic 主题会给轴文字、网格、线条额外加一层透明度，所以 01 里的网格线实际看不见，轴文字也发灰。
5. **出不了 PNG**。技能只会输出 renderer（HTML），而且把「图片文件」列进了不接的活。目标图其实是 matplotlib 出的 PNG（宋体中文），技能里既没有导出办法，也没提中文字体和负号会变方块的问题。

## 改了什么

- 新增 `renders/08-combo-dual-axis.html`：G2 组合图模板，包含双 y 轴（独立比例尺、零点对齐）、正负条件色柱、平滑主线和点标注、旋转标签的竖向参考线、横向 50% 线与零线、中文衬线字体、深色模式、窄屏适配（参考线文字移到图例下方），CDN 失败时降级成表格。
- 新增 `scripts/combo_chart.py`：用 matplotlib 离线出 PNG，靠 JSON 规格驱动。会自动挑系统里有的中文字体、处理负号、对齐两轴零点、平滑曲线不过冲（只用 numpy，不需要 scipy）。
- 新增 `scripts/export-png.sh`：用无头 Chrome 把任意一个 render 截成 2 倍清晰度的 PNG，可以选深色。
- 修改 `SKILL.md`：
  - description 加了触发词（双轴 / 组合图 / 参考线 / 导出 PNG）。
  - 菜单表加了「G2 组合图」和「PNG 文件」两行，还加了一句直接路由：出现两种单位、柱+线或点位虚线，就从 08 开始。
  - 双轴规则从「禁止」改成「可以拆，也可以按 08 的方法画双轴」。
  - 写明「有含义的竖线要画」「按含义上色可以用」。
  - 新增「G2 v5 组合图硬坑」「出 PNG 时的中文坑」两条。
  - 新增「复杂 / 分析型图表清单」，共 9 条：轴、系列、条件样式、参考线、标注、文字、字体、交付形态、自检。
  - 不接的活里给图表 PNG 开了例外。
- 修了 `renders/01-chart-g2.html` 的一个小 bug：网格线和轴文字补上 `*Opacity:1`，网格线现在能看见了。
- `backup/` 和其他模板都没动。
