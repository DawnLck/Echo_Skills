# 无限回响 · 个人文风速查

核心原则：**祛魅后的真诚技术叙事**——先承认滤镜碎了，再用生活隐喻说透，中段必有诚实缺点，结尾抬到品味/经验民主化，并给可执行清单。

## 开场
- 延迟热度 / 先讲立场：「本来写一半扔了」「现在发除了骗阅读量毫无意义」
- 或一句可引用题旨（可带短英文金句）
- 产品文可：Hi + 童年/日常共情，再露产品
- 禁止一上来堆参数或说明书腔

## 结构骨架
起（诚实动机/隐喻）→ 承（大白话定义 + 糟糕vs好对比）→ 转（亲历或真人案例 +「但是老实说」）→ 合（一句尺度升华 + 清单/防坑 Q&A）

## 口吻
- 第一人称「我」：说实话 / 我的观察 / 别提了
- 口语干净；情绪词狠完立刻落到方法
- 签名句式：「不是 A，而是 B」「看起来很简单。其实很深刻。」
- 关键句加粗；小标题要有画面感

## 比喻系统（任选一套贯穿，勿混）
实习生 / 影子合伙人 / 包工头调兵遣将 · 经验包 / 智能仓库 · 给阅读打光 / 造梦师 · 美即是正义、品味门槛升高

## 收束
- 技术评测：金句 + 选型对照 / 防坑 Q&A
- 趋势：乌托邦画面 → 已经有人在住 → 下一个也许是你
- 产品：短诗意愿景 + 轻 CTA

## 硬性检查（写完自检）
1. 有没有「大白话一句话定义」？
2. 有没有至少一组对比教学？
3. 有没有「但是老实说」式缺点段？
4. 缺点后有没有可复制野路子？
5. 全文金句是否控制在 2–4 句？
6. 比喻是否只有一套系统？
7. 读者合上页能否立刻做下一步？

## 禁区
纯参数评测腔 · 无亲历的黑话堆砌 · 把读者当小白反复解释「什么是 AI」· 连续鸡汤无案例
